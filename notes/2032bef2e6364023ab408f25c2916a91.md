## cpu_particles_2d.h

### CPUParticles2D::_particles_process(double p_delta)
核心的例子效果计算的函数，其中用了挺多godot封装了的数据结构，打算单开一篇去做，先关注函数本身吧

- [ ] 给数据结构单开一篇

上来先是生命周期计算

```cpp
	double prev_time = time;
	time += p_delta;
	if (time > lifetime) {
		time = Math::fmod(time, lifetime);
		cycle++;
		if (one_shot && cycle > 0) {
			set_emitting(false);
			notify_property_list_changed();
		}
	}

```

周期大于生命周期就进行取余，然后加周期，如果是一次的cycle那就关闭发射器并且通知一个事件

	Transform2D emission_xform;

local_coords = false（默认）时，粒子在世界空间里模拟——发射器飞走了，已经喷出的粒子留在原地。要实现这个，就必须在粒子出生那一刻把它从“节点局部空间的形状参数”变换到世界空间。这段就是在算那个变换。

interpolated_follow 来自于` bool follow = !local_coords && get_tree()->is_physics_interpolation_enabled();`
